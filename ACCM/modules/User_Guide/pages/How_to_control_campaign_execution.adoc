= How to control Campaigns execution

== Introduction

This section provides the steps required to control the execution of campaigns.

== Manual start

Initiates immediate execution of the campaign, bypassing any previously defined schedule.

[NOTE]
====
**Allowed Manual Start States:** `Scheduled`, `NotScheduled`.
====

To manually start a campaign using the {app-short-name} WebUI, you must execute the following steps:

. Click the "CAMPAIGNS" option on the menu bar displayed on top of the screen:
+
image::CAMPAIGNS_menu.png[align="center"]

. All the campaigns will be listed:
+
image::CAMPAIGNS_menuSection.png[align="center"]

. Locate the campaign to start and click the Manual Start button on the row. Please note that the Manual Start option is only available for NotScheduled campaigns:
+
image::CAMPAIGNSSection_notScheduled.png[align="center"]

. Confirm the action:
+
image::CAMPAIGNSSection_confirmManualStartAction.png[align="center"]

== Cancel

Aborts the currently active upgrade or rollback tasks in Altiplano and stops the campaign's progression.

[NOTE]
====
**Allowed Cancel States:** `Executing`, `ExecutingRollback`.
====

To cancel a campaign using the {app-short-name} WebUI, you must execute the following steps:

. Click the "CAMPAIGNS" option on the menu bar displayed on top of the screen:
+
image::CAMPAIGNS_menu.png[align="center"]

. All the campaigns will be listed:
+
image::CAMPAIGNS_menuSection.png[align="center"]

. Locate the campaign to cancel and click the Cancel button on the row. Please note that the Cancel option is only available for Executing or Executing Rollback campaigns:
+
image::CAMPAIGNSSection_executing.png[align="center"]

. Confirm the action:
+
image::CAMPAIGNSSection_confirmCancelAction.png[align="center"]

[NOTE]
====
When the cancel action is executed, the campaign will remain in "Executing" status until Altiplano effectively aborts the activity in progress. This can take time, and while the process lasts, the message "The cancellation is being executed" is shown.

image::CAMPAIGNSSection_canceling1.png[align="center"]

image::CAMPAIGNSSection_canceling2.png[align="center"]
====

[NOTE]
====
A campaign created in ACCM if it is cancelled by the user and if the same campaign is In-progress in Altiplano Software manager then:

* If the operator wants to clean up fully the software campaign ,  delete action has to be performed for the campaign.
====

== Retry

Re-executes the update sequence specifically targeting the failed or canceled element activities, intelligently skipping already successful elements.

[NOTE]
====
**Allowed Retry States:** `Error`, `Canceled`.
====

To retry a campaign using the {app-short-name} WebUI, you must execute the following steps:

. Click the "CAMPAIGNS" option on the menu bar displayed on top of the screen:
+
image::CAMPAIGNS_menu.png[align="center"]

. All the campaigns will be listed:
+
image::CAMPAIGNS_menuSection.png[align="center"]

. Locate the campaign to retry and click the Retry button on the row. Please note that the Retry option is only available for Error or Canceled campaigns:
+
image::CAMPAIGNSSection_error.png[align="center"]

. Confirm the action:
+
image::CAMPAIGNSSection_confirmRetryAction.png[align="center"]

== Rollback

Reverts a specific element back to its prior stable version. If a device is selected under a "Device and all its ONTs" matrix, all subtended ONTs are rolled back automatically.

[NOTE]
====
**Allowed Rollback States:** Campaign (`Success`, `Error`, `Canceled`, `ExecutingRollback`) AND Element (`Success`).
====

To rollback an element (device or ONT) using the {app-short-name} WebUI, you must execute the following steps:

. Click the "CAMPAIGNS" option on the menu bar displayed on top of the screen:
+
image::CAMPAIGNS_menu.png[align="center"]

. All the campaigns will be listed:
+
image::CAMPAIGNS_menuSection.png[align="center"]

. Locate the campaign that contains the element to rollback, and click the Detail button on the row:
+
image::CAMPAIGNSSection_detail.png[align="center"]

. All the clusters for the campaign will be listed:
+
image::CAMPAIGNSSection_clusters.png[align="center"]

. Locate the cluster that contains the element to rollback, and click the Details button on the row:
+
image::CAMPAIGNSSection_detail.png[align="center"]

. The list of elements for the cluster will be listed:
+
image::CAMPAIGNSSection_clusterElements.png[align="center"]

. Locate the element to rollback and click the rollback button. Please note that the Rollback option is only available for Success or Rollback Error elements:
+
image::CAMPAIGNSSection_detail.png[align="center"]

. Confirm the action:
+

image::CAMPAIGNSSection_confirmRollbackAction.png[align="center"]
